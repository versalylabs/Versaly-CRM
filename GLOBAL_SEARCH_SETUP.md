# Global Search & Command Palette

## Usage

- Press **Ctrl + K** on Windows/Linux.
- Press **Command + K** on macOS.
- Or use the visible **Search CRM...** button on larger screens.

## Search coverage

The command palette searches:

- Leads
- Tasks
- Proposals
- Calendar events
- Outreach records
- Users (Admins and Managers)
- CRM pages

## Quick actions

When the search box is empty, it provides shortcuts to:

- Create/open Leads
- Create/open Tasks
- Schedule an event
- Create/open Proposals
- Log outreach
- Compose email

## Keyboard controls

- `Ctrl/Command + K`: Open or close search
- `Arrow Up/Down`: Navigate results
- `Enter`: Open selected result
- `Esc`: Close

No database migration is required for this feature.
